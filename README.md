\# 🍫 可可与嫑嫑 · 甜点工坊



一款模拟经营 + 探险的 Electron 桌面游戏。



\## 🎮 核心玩法



\- 🏭 工坊系统：制作 8 种甜点产品

\- 🌱 农场系统：种植收获巧克力豆

\- 📋 订单系统：每日 5 个随机订单

\- 🏆 成就系统：7 大类成就

\- 🗺️ 探险地图：10 个岛屿，含钓鱼、挖矿、数独、烹饪等

\- 🏛️ 挑战塔：92 层挑战

\- 🏪 商城系统：签到 + 道具购买



\## 🛠️ 技术栈



\- Electron 28

\- 纯原生 JavaScript（无框架）

\- localStorage 持久化



\## 🚀 运行



```bash

npm install

npm start
